# 在埃及，看懂千年 — 人文旅行杂志

一份**单文件离线阅读版**的埃及随身手册。整个页面（正文、排版、22 张配图）都打包在一个 `index.html` 里，不依赖任何外部资源，下载后可离线打开。

## 在线访问

部署在 GitHub Pages 上，直接用浏览器打开即可：

**https://zhuoyizhao661-beep.github.io/egypt-handbook/**

## 本地使用

```bash
# 直接双击打开，或用浏览器
open index.html
```

也可以把 `index.html` 拷进手机 / U 盘随身带着，断网状态下照常阅读。

## 内容包括

- 金字塔、神庙、墓葬等主要遗址的看点与背景
- 古埃及神祇与《亡灵书》相关的图像解读
- 大埃及博物馆（GEM）参观信息
- 文末附图片来源与参考链接

文中图片来自大英博物馆、大都会艺术博物馆、GEM 等机构的公开资料，出处见页面末尾。
